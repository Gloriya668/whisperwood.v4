# Whisperwood v4.0

Whisperwood v4.0 是一个基于手势识别交互的暗黑童话风网页小游戏。玩家通过不同手势进行施法、防御和反击，与敌人进行对弈。

## 项目内容

- 手势识别交互
- 游戏规则引擎
- 角色/敌人视觉素材
- 背景音乐与音效
- 暗黑童话风 UI 页面
- 产品需求文档 PRD

## 文件说明

- `index.html`：网页入口
- `style.css`：页面样式
- `app.js`：主逻辑
- `gesture.js`：手势识别逻辑
- `ruleEngine.js`：游戏规则逻辑
- `sfx.js`：音效逻辑
- `bgm.js`：背景音乐逻辑
- `PRD.md`：产品需求文档
- `demon-eye.png`：敌人素材
- `游戏过程背景图.png`：游戏背景图
- `bgm.mp3`：背景音乐

## 运行方式

直接双击 `index.html`，或用浏览器打开即可预览。

如果部分功能需要摄像头权限，请使用 Chrome 或 Edge 浏览器，并允许摄像头访问。
